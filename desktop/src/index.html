RustDesk

This preview verifies the RustDesk 1.5.0 Windows x64 executable against a reviewed SHA-256 digest. Other builds, including macOS, remain blocked until their release identity is reviewed. Authentication and host permissions remain in RustDesk.

No application selected

RustDesk is not bundled. Its existing server configuration is used unchanged. No password, VPN credentials or unattended-access setting is stored here.

Permission comes first

Ask the owner to approve access in RustDesk. Select view-only there before interacting. File transfer has its own host permission.

No direct-IP launch is provided: an IP address alone does not establish peer identity or encryption.

What stays local

Computer names, RustDesk IDs, optional IP labels and the selected engine path are saved on this computer.

No passwords, clipboard contents, screen recordings or analytics are collected.

About this milestone

The shared Windows/macOS UI replaces MFC. Remote sessions open in the external RustDesk window. The local lab measures a separate synthetic WebRTC path; it is not a RustDesk performance result.

Repository license unchanged (GPL v2 file). RustDesk is independently licensed AGPL-3.0. No RustDesk source is copied or linked. Engine redistribution and deeper integration need a license review.
